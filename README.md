# Square Run n' Gun
- Dodge the incoming enemies and shoot them to gain points. <br>
- Survive as long as possible. <br>
- Bullets fire backwards. <br>
- Red enemies are worth 1 point, blue enemies are worth 5 points. <br>
- Enemies spawn at fixed random intervals, with varying heights. <br>

## Controls:
- **A - Move Left**
- **D - Move Right**
- **S - Shoot Bullet**
- **Space - Jump**
